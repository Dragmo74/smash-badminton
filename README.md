# Smash Badminton

Appli web pour organiser un tournoi de badminton, à la mêlée ou en équipes fixes : tirage des équipes, scores, classements et finales.

Elle tient en une page, s'installe sur l'écran d'accueil du téléphone et marche hors ligne. Le tournoi est enregistré sur l'appareil.

**Ouvrir l'appli :**

- https://smash-badminton.pages.dev/ (Cloudflare Pages)
- https://dragmo74.github.io/smash-badminton/ (GitHub Pages)

Les deux adresses servent la même appli, mais chacune garde ses tournois à part : mieux vaut en choisir une et s'y tenir.

Ce dépôt contient uniquement les fichiers publiés : `index.html` (toute l'appli), `manifest.webmanifest`, `sw.js` (usage hors ligne) et `icons/`. Chaque envoi sur la branche `main` met à jour les deux sites.
